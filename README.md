# Personal Homepage Draft

A private first draft of a research homepage inspired by a clean, editorial academic-site layout.

## Preview locally

Open `index.html` directly, or serve the folder with any static file server.

## Personalize before publishing

Update these items in `index.html`:

- Display name and Chinese name
- Contact email / Google Scholar / CV links
- Internship descriptions and exact team names
- Education dates, advisors, publications, and awards
- Current research details when they become public

Replace `assets/avatar.png` with a personal portrait if desired.

## Privacy

This repository is intended to remain private during drafting. No analytics or tracking scripts are included, and no deployment workflow is configured.
